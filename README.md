# MEVIC

Framework metodológico para la evaluación, análisis y fortalecimiento de la ciberseguridad.

**Estado:** versión 0.1, propuesta en fase de diseño. Su utilidad, consistencia y reproducibilidad aún no han sido validadas con casos de estudio.

## Fases
01 Preparación · 02 Prevención · 03 Identificación · 04 Análisis · 05 Mitigación · 06 Verificación

## Estructura
- `docs/`: documento del framework y glosario
- `framework/`: fases, protocolos y matrices
- `laboratorios/`: laboratorios FC-LAB-001 a 007
- `plantillas/`, `scripts/`, `casos-estudio/`, `resultados/`

## Uso responsable
Todo procedimiento de este repositorio debe ejecutarse únicamente en entornos propios o con autorización expresa y documentada. No se publican credenciales, datos personales ni información de terceros.
